# Convenções de Código

.NET: configurações compartilhadas em `Directory.Build.props` habilitam nullable, implicit usings, warnings as errors, AnalysisLevel e LangVersion latest. WEB usa Vue/TS e scripts do `web/OrderHub.Web/package.json`; formatos/lint configurados no projeto devem ser mantidos.

Nomes e estrutura devem seguir o módulo e exemplos vizinhos. Endpoints agrupados por área, contratos explícitos, comandos/queries separados. Consulte `AGENTS.md`, `AGENTS.md` e exemplos de código e configs reais. Convenções não identificadas além dessas devem ser tratadas como **A confirmar**, não inventadas.
