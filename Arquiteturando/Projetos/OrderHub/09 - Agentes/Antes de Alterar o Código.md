# Antes de Alterar o Código

- [ ] Leia `AGENTS.md` e instruções da pasta afetada.
- [ ] Identifique contexto, requisito, spec vigente e change ativa relevante.
- [ ] Busque exemplos e testes análogos; verifique estado Git atual.
- [ ] Trace fluxo e camada; determine efeitos sobre API, WEB, tenant, dados e integrações.
- [ ] Revise ADRs e Design System/convenções aplicáveis.
- [ ] Não leia/copie segredos de `.env`; use configuração documentada e redigida.
- [ ] Implemente no padrão existente sem duplicar abstração ou regra.
- [ ] Atualize testes/spec/docs segundo DoD.
- [ ] Reporte arquivos alterados, validações realmente executadas e limitações.

Relacionado: [[Diretrizes para Agentes]], [[Checklist de Desenvolvimento]].
