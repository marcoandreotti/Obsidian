# Checklist de Desenvolvimento

- [ ] Requisito e contexto confirmados na spec/fonte.
- [ ] Padrão local e ADR revisados.
- [ ] Camadas/dependências corretas.
- [ ] Tenant, autenticação/autorização e validação tratados.
- [ ] Persistência/transação/read-model e integrações considerados.
- [ ] WEB segue Design System e acessibilidade quando aplicável.
- [ ] Testes relevantes criados/atualizados e executados.
- [ ] Build/lint/typecheck/DoD da raiz executados quando prescritos.
- [ ] OpenSpec/docs/ADR atualizados conforme processo.
- [ ] Resumo informa alterações e verificações reais.

Fonte normativa: `AGENTS.md` e spec/change; este checklist é índice auxiliar. [[Diretrizes para Agentes]]
